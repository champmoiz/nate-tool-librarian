=====================================================================
NATE — HUMOR POOL
=====================================================================
How this file works:

The Nate server reads this file on every /chat request. It picks
THREE random STYLE HINTS and ONE random JOKE (with 50% probability).
Both get injected into the system prompt as a "HUMOR AMMUNITION"
block that Nate can use or ignore.

Editing this file is safe. Nate re-reads it every request. Add
lines, remove lines, reorder — changes take effect on the next
message.

Format rules:
  - Sections are marked with === HEADER ===
  - Items start with "- " (dash space)
  - Blank lines and # comments are ignored
  - Don't remove the section headers
=====================================================================
